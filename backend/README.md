# Skinlytics — backend

FastAPI modular monolith (`docs/ARCHITECTURE.md` §3-4, ADR-005). Python 3.11+, `uv` for deps.

Read `/AGENTS.md` and `/docs/CONVENTIONS.md` before adding code here — service anatomy
(`router.py`/`service.py`/`schemas.py`/`models.py`/`deps.py`), data-ownership rules, and
API conventions are defined there, not in this file.

```bash
uv run uvicorn app.main:app --reload   # http://localhost:8000, docs at /docs
uv run ruff check .
uv run mypy app
uv run pytest
```

`app/core/security.py` (`require_user`/`require_role`) is the only auth code — no
endpoint re-implements JWT verification. Better Auth (in `web/`) is the auth authority;
this service only validates JWTs against its JWKS (ADR-002/003).

Alembic migrations: `uv run alembic revision --autogenerate -m "..."` /
`uv run alembic upgrade head` (needs a running Postgres — see root `docker-compose.yml`).
Better Auth's identity tables (`user`, `session`, `account`, `verification`, `jwks`) are a
**separate migration stream** generated by the Better Auth CLI in `web/`, not Alembic —
never hand-edit or Alembic-migrate them.
