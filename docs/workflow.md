 AI Skin Intelligence Workflow

 User Workflow

1. User registers an account.
2. User logs in using email and password.
3. JWT token is generated after successful login.
4. User creates a Skin Profile.
5. User enters Lifestyle information.
6. User views the dashboard.

 Future Workflow (Milestone 2)

7. User uploads a skin image.
8. AI analyzes the skin image.
9. AI predicts skin conditions.
10. AI recommends suitable skincare products.
11. User follows the recommended skincare routine.
12. User tracks progress over time.

 Admin Workflow

1. Admin logs in.
2. Admin manages skincare products.
3. Admin manages ingredients.
4. Admin monitors user activity.

 Dermatologist Workflow

1. Dermatologist logs in.
2. Reviews user profile.
3. Reviews AI assessment.
4. Provides professional recommendations.
