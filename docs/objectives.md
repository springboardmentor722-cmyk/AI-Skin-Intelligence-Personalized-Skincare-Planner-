 Project Objectives

The objective of this project is to build an AI-powered skincare intelligence platform that helps users understand their skin condition and receive personalized skincare guidance.

 Main Objectives
- Collect user skin profile details
- Track lifestyle, sleep, hydration, and environmental exposure
- Analyze skin concerns
- Generate personalized skincare routines
- Support different roles: User, Consultant, Dermatologist, and Admin
- Provide dashboards and progress tracking
