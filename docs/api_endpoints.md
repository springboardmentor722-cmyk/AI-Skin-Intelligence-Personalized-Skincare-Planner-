
API Endpoints

Authentication

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | /register | Register a new user |
| POST | /login | Login and generate JWT token |

 Skin Profile

| Method | Endpoint | Description |
|--------|----------|-------------|

| GET | /skin-profile/{id} | Get skin profile |
| PUT | /skin-profile/{id} | Update skin profile |
| DELETE | /skin-profile/{id} | Delete skin profile |
