# AI-Skin-Intelligence-Personalized-Skincare-Planner-
AI Skin Intelligence & Personalized Skincare Planner is an AI-powered skincare platform that provides personalized skincare recommendations based on a user's skin profile, lifestyle, sleep, hydration, and routine consistency.

Project Description

The project uses Artificial Intelligence and Machine Learning to analyze user-specific skin information and generate personalized skincare recommendations. It provides a skin health score, product recommendations, ingredient information, and customized skincare routines.

The system also includes face scan functionality, user authentication, dashboard visualization, and database integration using PostgreSQL and MongoDB.

Project Structure

The project contains two main parts:

Backend – Handles authentication, APIs, database operations, skin analysis, ML inference, product recommendations, skincare routine generation, and skin health scoring.

Frontend – Provides the user interface, face scan functionality, dashboard, skin score visualization, and communication with the backend APIs.

Project Workflow

User Registration/Login → Skin Profile → Face Scan/Data Collection → AI/ML Analysis → Skin Health Score → Ingredient Analysis → Product Recommendation → Personalized Skincare Routine → Dashboard

Project Objective

The main objective of this project is to develop an intelligent and personalized skincare platform that helps users understand their skin and receive customized skincare recommendations using AI and Machine Learning.
